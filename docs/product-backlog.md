# Product Backlog

## 1. Deskripsi Produk
Sipesan merupakan aplikasi berbasis Flutter yang dikembangkan untuk mempermudah pengguna melakukan pemesanan secara digital.

## 2. Product Goal
Membangun aplikasi yang mempermudah pengguna melakukan pemesanan dan mengelola pesanan.

## 3. Product Backlog

| ID | Fitur | Deskripsi | Prioritas |
|---|---|---|---|
| PB-01 | Login | Pengguna dapat masuk ke aplikasi | High |
| PB-02 | Register | Pengguna dapat membuat akun | High |
| PB-03 | Dashboard | Menampilkan halaman utama | High |
| PB-04 | Daftar Menu | Menampilkan daftar menu | High |
| PB-05 | Detail Pesanan | Menampilkan detail pesanan | Medium |
| PB-06 | Keranjang | Menyimpan item pesanan | High |
| PB-07 | Checkout | Memproses pemesanan | High |
| PB-08 | Riwayat Pesanan | Melihat pesanan sebelumnya | Medium |

## 4. Prioritas Pengembangan
- High: Fitur utama.
- Medium: Fitur pendukung.
- Low: Fitur tambahan.

## 5. Kesimpulan
Product Backlog digunakan sebagai daftar kebutuhan dan fitur pengembangan aplikasi Sipesan.
